Novidade do **app Desktop** está nas **notas de versão do próprio app**; o changelog da CLI do Claude Code não as
traz. Em 2026-10-15 ler só o changelog da CLI deu "não houve mudança", e estava errado: o owner colou as notas do app
(memory/sessions/2026-10-15-novidades-do-app-desktop.md:12).

**Como usar:** pergunta sobre o app → peça as notas de versão do app ou procure a fonte do app; o changelog da CLI
serve só para a CLI. Parente de [[feedback_pesquisar_fonte_primaria_antes_de_desenhar]].
